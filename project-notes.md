# K2176 Project Notes

## Project

- Project name: Number Garden
- Target students: 6-year-old English learners
- Teaching focus: review numbers `1-100`; practice skip counting by `5s` and `10s`
- Game style: friendly counting garden with flowers, pots, nests, number board, and counting paths
- Format: static HTML/CSS/JavaScript only

## Game Structure

- Level 1: Number Board - students find spoken/printed numbers from `1-100`
- Level 2: Count by 10s - students choose the next number in `10s` counting
- Level 3: Count by 5s - students choose the next number in `5s` counting
- Level 4: Counting Path - students tap numbers in order by `5s` or `10s`
- Level 5: Garden Challenge - simple review of number recognition, `5s`, `10s`, and group counting

## Teacher Notes

- The game has 25 short tasks.
- The review section stays within number recognition, counting by `5s`, counting by `10s`, and group counting.
- Wrong answers give a short counting hint without revealing the correct answer.
- Each task has a `Listen` button using browser speech synthesis.
- After students choose an answer, the page plays short audio feedback.
- Correct answers grow the flower score and unlock the next task.
- No APIs, external services, build tools, or generated audio files are used.
- The page is responsive for desktop, iPhone, iPad, and Android phones/tablets.
